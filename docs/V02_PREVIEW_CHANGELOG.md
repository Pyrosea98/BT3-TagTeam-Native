# 0.2-preview

## English

- Wider beam assist range for the expanded maps.
- Retry opening the Modded Modes menu when its native objects are still loading.
- CPU transformations recognize Power Scale fighters with more than one million HP.
- Retain the CPU transformation families accepted in the local trials, including Super Goku and Vegeta's accepted forms.
- Prevent the confirmed oversized Mega Instinct Vegeta transformation for extra fighters before loading, for both human and CPU control. Leader transformations retain their existing path.
- Keep the beam assist and transformation diagnostics.

Known limits: effects memory requirements have not been calculated for the complete roster. Mega Instinct is blocked for extra fighters. A failure after destructive model replacement still requires restarting; safely restoring all model/effect ownership is deferred. Ultimate Boost, Rush Assist and effects-arena resizing are deferred to v0.3. The existing shutdown warning remains.

## Español

- Mayor alcance de la asistencia de rayos en los mapas ampliados.
- Reintento de apertura del menú de modos modificados mientras sus objetos nativos siguen cargando.
- Las transformaciones de CPU reconocen luchadores de Power Scale con más de un millón de puntos de vida.
- Se conservan las familias de transformación de CPU aceptadas en las pruebas locales, incluidas las formas aceptadas de Goku y Vegeta de Super.
- Se impide la transformación de Vegeta Mega Instinto que supera la memoria reservada para luchadores adicionales, antes de cargarla, tanto con control humano como de CPU. Los líderes conservan su ruta existente.
- Se mantienen los diagnósticos de asistencia de rayos y transformaciones.

Limitaciones conocidas: no se han calculado los requisitos de memoria de efectos de todo el plantel. Mega Instinto está bloqueado para luchadores adicionales. Un fallo después de sustituir y destruir recursos del modelo todavía requiere reiniciar; la restauración segura de todos los recursos queda pendiente. Ultimate Boost, Rush Assist y la ampliación de las áreas de efectos quedan para v0.3. Se mantiene la advertencia existente al cerrar.

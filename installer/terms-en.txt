WHAT IT IS
Dragon Ball Z: Budokai Tenkaichi 3 (Power Scale BETA 1.5.1) running natively on Windows, with the Tag Team mod built in. No emulator and no separate Python installation are needed.

WHAT YOU NEED TO PROVIDE
You must have your own copy of the Power Scale BETA 1.5.1 disc image. No game discs, game files, interface art or BIOS are included in this installer. The first time you run the game it checks your disc image, builds an expanded copy of it inside the game's data folder and prepares the interface art from it. Your original disc image is never modified.

YOUR DATA
Everything the game creates (imported data, saves, settings, logs) is stored in the "data" folder inside the install folder. A starting save is included (you choose whether it starts with all content unlocked); an existing save is never overwritten. Uninstalling keeps your game data unless you tick the option to remove it. No personal data is collected and nothing is sent over the network.

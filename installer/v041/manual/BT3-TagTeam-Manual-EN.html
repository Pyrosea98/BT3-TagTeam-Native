BT3 Tag Team + Real Power Scale — 0.4.1

Installation

  1. Run the 64-bit Windows installer. Choose a folder with enough free space; no separate Python or BIOS is needed.
  2. Choose normal or 2x maps. Both retain the same fixes. You can enable recommended settings and an unlocked starting save.
  3. Open Play.exe, choose a supported ISO from the list below and wait for import to finish. Your original ISO is not changed. Allow about 8 GB free for game data, in addition to the application.
  4. The game uses extracted files, so it does not need to keep a second 8 GB ISO. Your map-size choice is applied during import.

Controls and settings

  1. F1 or Select > Settings opens mod settings. Square saves; existing settings and progress are kept on reinstall.
  2. Recommended fusion controls alternate the participating players every 10 seconds. Change this under Fusion settings.
  3. Includes Team Battle, co-op, training, spectating, team tournament, fusion/defusion, revival and beam/rush/ultimate assists. Scenarios remains marked Coming soon.
  4. Check player, controller and keyboard assignments under Controls. Credits are under System > Credits and thanks, and About.

Data and support

  1. Imported data, logs, settings and saves live in the installation’s data folder. A data-root.txt file can select another location. Do not delete saves to change maps.
  2. To prepare another map variant, use a fresh installation/data folder and keep your saves. Reinstalling does not change an already completed import.
  3. If launch fails, check data/launcher.log and data/game.log. Do not mix this port with executable/controller files from the older version.
  4. Android is published separately. This installer does not bundle an APK.

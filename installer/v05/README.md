# Windows 0.5.alpha installers and release channels

Full Setup is for a new folder. It uses the authenticated 0.4.1 ISO importer, then applies the current alpha before the first game launch. Original Power Scale BETA 8 or the compatible R4 normal/2x ISO listed in the manual is required. No ISO is bundled or modified. Normal and optional 2x maps are both supported.

Update Setup is for an existing imported 0.4.1 or completed 0.5.alpha installation. Choose the existing game folder. No ISO re-extraction. Saves, achievements, settings and map choice are kept; modified or unsupported package inputs fail preflight. The journal supports rollback and interruption recovery. A single-writer lock prevents concurrent updates. Full Setup refuses to overwrite an installation; use Update Setup instead.

The installer offers Stable or Nightly (preview) and optional launch checks. Download/install requires approval; offline failures let you continue. Use the Start menu Check for updates shortcut or Play.exe --updates to change preferences. Nightly currently includes the published alpha; this is a release channel, not an automatic CI build promise. Stable never downgrades an installed preview. Each published update needs an asset named BT3-TagTeam-<version>-Windows-Update.zip, GitHub SHA256 digest, compatible schema-1 manifest/recipes, and notes containing <!-- bt3-revision: UNIQUE_REVISION --> matching release-profile.json. Change revision even for a replacement under the same tag. This prevents repeated update notices. Source edits become available only after a compatible binary/data package is built and published.

Downloads come from the official repository over HTTPS, match GitHub's SHA256 and size, and extract only payload/update.json and payload/blobs. Downloaded Python scripts are never run. The installed engine preflights every target and maintains rollback backups. A new/incompatible ISO needs new import/data recipes; there is no promise of arbitrary ISO compatibility. APK delivery is separate.

Build using the F: stage scripts in source/analysis/codex-installers-20261107, existing pc-release-v041/payload and current verified alpha update bundle. Compile installer.iss and update-installer.iss with Inno Setup 6.7.3; Play.cs with the .NET Framework compiler. Keep stable release inputs unchanged. Run test_channels.py, test_update.py, real importer tests, exact normal/2x/earlier-alpha tests, and extracted Setup checks before publishing. Game source is unchanged by this installer batch.

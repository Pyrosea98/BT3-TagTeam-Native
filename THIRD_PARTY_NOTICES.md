# Third-party notes

This preview bundles BT3-Recomp, a private CPython runtime, Pillow, numpy, pycdlib, psutil, capstone, pyelftools, zstandard, comtypes and native runtime libraries. Source dependency licences and font licence copies are staged under notices where available. The full redistribution/attribution inventory still requires review before a public release. Game ISO, extracted game resources and Android tools are excluded.
